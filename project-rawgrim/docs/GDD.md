# Project Ascension
Version: 0.1

## Genre
Dark Fantasy Hero Management Auto-Battler

## Platforms
- Initial: Web
- Future: Windows and Android

## Gameplay
- Hero summoning
- Hero management
- Party formation
- Automated combat
- Tower progression
- Permadeath

## MVP
- 10 hero templates
- 4 classes
- 5 tower floors
- 5v5 combat
- 8 skills
- 1 boss

## Visual Direction
Dark fantasy, purple, black, and gold.
UI-first development.
No 3D assets required for the MVP.

## Hero Intelligence

Heroes use individual multidimensional personalities and deterministic Utility AI. Party strategy influences decisions according to each hero's discipline, but never bypasses combat validation. Persistent learning updates are deferred beyond the current foundation.

The accepted domain model, save migration, scoring bounds, and current limitations are documented in [AI_ARCHITECTURE.md](./AI_ARCHITECTURE.md).
